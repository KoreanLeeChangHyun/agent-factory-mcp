권위

2026-09-15 사용자 승인: 사용자 코드·공통 에셋·공개 SDK를 지원하고 workbench-sdk·workbench-build를 분리한다. 최신 기준은 제품 개요와 전체 구조다. workbench-runtime.md의 이전 선언형 본문은 이전 참고이며 JSON 전용 제한으로 최신 결정을 덮어쓰지 않는다.

사용자의 명시적 지시가 우선한다. 설계 문서는 채택된 의도를 나타내며 구현이나 날짜별 근거가 이를 자동으로 덮어쓰지 않는다. 필수 정책은 연결된 rule-platform을 함께 적용한다.

AI 표현은 .codex/skills/design-platform/이다. 소유권이나 설계 의미가 바뀌면 두 표현을 함께 갱신한다.
