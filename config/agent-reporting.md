# 외부 에이전트 보고

Agent Factory는 MCP 연결과 클라우드 관제 화면을 제공합니다. AI 모델을 호스팅하거나
실행하지 않습니다. 실제 작업은 사용자가 연결한 도구에서 수행합니다.

워크스페이스 관리자 권한으로 MCP 연결을 만들고, 도구에
`agent-factory://reporting/guide` 리소스를 읽도록 안내하세요. 새 관리자 연결에는
`agent:report` 범위가 포함됩니다. 기존 토큰에 권한이 자동 추가되지는 않습니다.
에이전트에게 구성 등록, 작업 등록, 시작·진행·입력 필요·종료와 결과를 보고하도록
지시하면 에이전트 Activity에서 확인할 수 있습니다.

기본 사이드바는 전체 보기와 에이전트 계층, 역할, 현재 작업 요약을 보여줍니다.
전체 화면에서는 대기, 진행 중·입력 필요, 최근 완료·실패·취소 작업을 확인합니다.
에이전트를 선택하면 책임·워크스페이스 범위·보고 소유자와 작업 이력이 나타납니다.
작업을 선택하면 보고된 진행률, 시작·종료 시간, 결과와 보고 이력을 확인할 수 있습니다.
연결된 일정 버튼은 실제 일정 항목을 열고, 문서 결과는 해당 문서를 엽니다.
관련 MCP 보고 로그 버튼은 표시된 보고와 함께 저장된 호출 기록만 보여줍니다.
다른 운영 로그를 포괄하는 콘솔은 아닙니다.

구성과 이력은 PostgreSQL에 보존되며 접속이 끊겨도 사라지지 않습니다. 새 연결에서도
같은 사용자와 에이전트·작업 ID로 이어서 보고합니다. 다른 사용자는 관리 권한이 있어도
해당 에이전트로 가장하여 보고할 수 없습니다. 상하위 관계는 보고 권한을 위임하지 않습니다.
등록한 사용자 단위의 신원이며 실제 AI 프로세스를 증명하는 기능은 아닙니다.

화면은 15초마다 갱신합니다. 최초 등록만 있으면 ‘보고 없음’, 진행 중 5분간 보고가
없으면 ‘보고 오래됨’을 표시합니다. 연결이 조용하다고 완료로 바꾸지 않으며 진행률을
추정하지 않습니다. 시작·종료는 서버가 보고를 받은 시각입니다. 완료 시에도 마지막으로
보고한 진행률을 유지합니다. 통신 오류에는 마지막 수신 자료임을 표시합니다.

동일 요청을 같은 키로 다시 보내면 원래 응답만 반환하고 이력을 중복 추가하지 않습니다.
다른 내용에 같은 키를 사용하거나 오래된 수정 번호로 보고하면 충돌을 반환합니다.
완료·실패·취소된 작업은 변경하지 않습니다. 결과는 종료 보고에 함께 담으세요.
다시 시도하려면 새 보고 작업을 만들고 같은 일정 항목을 연결할 수 있습니다.
일정의 상태·기간·담당자·완료 조건은 보고로 변경하지 않습니다. 이력이 연결된 일정 항목의 삭제는 차단됩니다.

작업 배정, 일정 연결, 상위 작업은 등록 후 고정됩니다. 잘못 등록한 작업은 취소한 후
새 ID로 등록합니다. 에이전트 구성의 이름·역할·책임·상위 관계는 수정 번호와 함께
갱신할 수 있습니다. 문서는 현재 존재하는 같은 워크스페이스 문서만 연결할 수 있습니다.
외부 HTTP(S) 결과 링크는 보고자가 제공한 참조이며 서버가 내용을 확인하지 않습니다.

화면에는 최대 1,000개 구성과 최근 1,000개 작업을 표시하며 초과 시 안내합니다.
작업 UUID로 직접 읽는 MCP/API는 유지됩니다. 이력은 50개씩 이전 보고를 불러옵니다.
AI용 상세 계약과 JSON 예시는 `docs/external-agent-reporting.md`에 있습니다.
